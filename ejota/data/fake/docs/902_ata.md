# ATA de Projeto — EJ 26-902 (FICTÍCIO)
## Dificuldades
Os dados de faturamento foram solicitados ao cliente em 04/08 e só foram recebidos em 15/09.
O cliente remarcou duas vezes a reunião de validação do levantamento.
A prorrogação prevista no contrato não foi formalizada com o cliente.
## Lições Aprendidas
LA-1: Definir no kickoff um responsável do cliente pelo envio de dados, com data combinada.
LA-2: Formalizar por e-mail a prorrogação de prazo sempre que o cliente atrasar o envio de informações.
