# ATA de Projeto — EJ 26-901 (FICTÍCIO)
## Dificuldades
Na reunião de 26/08 o cliente pediu a criação de uma identidade visual nova, e a equipe aceitou incluir a demanda sem aditivo contratual.
A cada reunião de validação o cliente trouxe novas demandas para o plano de marketing.
## Lições Aprendidas
LA-1: Toda demanda fora do escopo deve gerar aditivo com novo prazo antes de ser iniciada.
LA-2: Definir na proposta o número máximo de rodadas de revisão.
